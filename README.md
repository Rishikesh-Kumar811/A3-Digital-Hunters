## ✨ Key Features

<br/>

### 1. 🌌 Holographic Sci-Fi Hero & Astronaut HUD Engine
- **Multi-Layer Stacking**: Deep spatial z-index composition pairing the astronaut subject with high-tech HUD vector rings.
- **Dynamic Ambient Lighting**: Custom CSS radial gradient overlays delivering intense neon cyan, magenta, and electric violet illumination.
- **Hardware Acceleration**: High-frame-rate entry animations utilizing CSS `transform` and `opacity` properties for smooth GPU rendering.

### 2. 🎮 Interactive Genesis & Game Studio Showcase
- **Curated Game Portfolios**: Multi-column responsive cards featuring studio titles (`Genesis`, `Hockey Arena`, `Park Odyssey`).
- **Engaging Hover States**: Perspective tilting, luminous card border glow, and interactive rating metrics.
- **Zero Layout Shifts**: Pre-allocated responsive image aspect ratios ensuring 0.0 Cumulative Layout Shift (CLS).

### 3. ⚡ Native HTML5 Popover Modal Navigation
- **Zero-JavaScript Modals**: Accessible, built-in light-dismiss popover elements for quick preview modals and navigation menus.
- **Focus Management**: Native browser keyboard navigation handling focus states and accessibility standards out of the box.
- **Top Layer Integration**: Automatically rendered in the browser top-layer viewport above all other DOM elements.

### 4. 🎨 Precision Responsive Breakpoints (Mobile to Ultra-Wide)
- **Universal Fluid Scaling**: Sizing calculated via `clamp()` routines to maintain proportionate layout integrity across devices from 350px up to 4K ultra-wide displays.
- **Adaptive Touch Controls**: Mobile-first interaction targets optimized for handheld touchscreens and desktop cursor precision alike.

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Rishikesh-Kumar811/A3-Digital-Hunters.git
cd A3-Digital-Hunters
```

### 2. Launch with Live Server
Open `index.html` directly in any modern browser, or run a local development server:

```bash
npx serve .
```

Visit `http://localhost:3000` in your web browser.
